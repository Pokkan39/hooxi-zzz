# HOOXI 档案站稳定定位

## 产品定位

HOOXI 是粉丝制作的非官方剧情与角色档案站，不是养成 Wiki，也不复制官方 UI。站点聚焦角色、阵营与剧情资料的查阅和关联浏览。

## 页面职责

- `stories.html` 是代理人选人工作台：左侧展示当前代理人的主舞台，右侧提供搜索、阵营筛选与代理人名单；选择代理人时无需刷新即可更新信息，并可进入对应角色深链。
- `character.html` 承担完整角色档案。
- `faction.html` 承担阵营档案；工作台中当前代理人的阵营可直接跳转至对应阵营页。

## 设计语言

设计 DNA 来自游戏内“左主右辅、状态切换驱动反馈”的交互逻辑，但视觉表达采用 HOOXI 自有的 **Signal Workbench / midnight tape desk** 语言，不复刻官方界面。

## 内容边界

站点不承载等级、星级、养成数值，也不使用持续待机动画；信息呈现始终服务于剧情、角色与阵营档案浏览。

## 2026-07-19 游戏选角 DNA 校准

工作台布局取材自游戏内选角界面 DNA——左侧全屏高清人物舞台展示当前代理人，右侧以 `clip-path: polygon(25% 0, 100% 0, 100% 100%, 0 100%)` 大斜切面板覆盖式呈现 3 列花名册，斜边带主题色高光，右缘 `SELECT` 竖标随代理人主题色变化。桌面端标题、搜索、状态和花名册滚动区均按斜边设置安全缩进；`880px` 及以下改为上下堆叠并关闭斜边与高光线，中间宽度顶栏只保留搜索入口，避免导航挤成双行窄标签。

切人先触发 480ms 不透明斜切扫场 wipe，在约 240ms 中点提交新代理人的主题、立绘、信息、深链、URL 与 ARIA 状态；提交前回选当前代理人会取消待处理切换。背景使用 `requestAnimationFrame` 将真实指针视差与小幅自动漂移写入 `--bg-drift-x` / `--bg-drift-y`；`prefers-reduced-motion` 会关闭持续漂移、待机呼吸和扫场动画。

舞台资源采用 54 张本地标准化透明 WebP（1600×1800 RGBA）；`aria` 与 `sunna` 暂无可信全身透明立绘，按既定设计使用不超过 300px 的档案卡降级，不把卡面拉伸成伪全身图。舞台图片以容器高度为基准底部锚定，避免按宽度放大后裁成半身。

该布局为 HOOXI 自有设计语汇的**非官方诠释**——仿游戏选角的操作感受（左展右选、切换斜扫），但不复制官方 UI 组件、字体或色彩系统。HOOXI 继续使用 Signal Workbench / midnight tape desk 深色琥珀体系，与米哈游《绝区零》及其官方绳网无隶属关系。

## 2026-07-19 R1 实施合同

R1 采用“档案核层 + 录像店壳层”：首页和正式档案页默认可搜索、可分享、可降级；HOOXI PLAY 只在用户主动进入后加载沉浸资源。全站设计真相收敛到根目录 `design.md`，不再通过继续堆叠 `theme-zzz.css` 覆盖来定义新页面。

正式媒体统一引用 `media-catalog.js` 中已核验的媒体 ID。普通档案页使用本地封面或 HOOXI 自制 fallback，不在运行时请求 B 站接口或第三方图片代理；来源与权利状态遵循 `docs/media-source-policy.md`。未核验内容继续显示诚实空态，不用假统计、假 LOCK 或无功能按钮填满页面。

## 2026-07-21 React 游戏客户端式工作台收口

`stories.html` 只保留正式 React 挂载点，`src/stories.jsx` 是选角交互源，构建产物为 `stories.js`。界面继续沿用 HOOXI 的 Parallel Skew Roster Stage：桌面左侧全身人物舞台和基础/技能/装备轨，右侧主题色斜切花名册；搜索与收藏按需展开，不复制官方组件或文本。

移动端改为舞台、档案信息、花名册的纵向阅读顺序，并禁止首次渲染因选中卡自动滚动到名单中段。用户主动切换角色后仍会把选中卡滚入名单可视区；减少动效模式取消空间位移和 wipe，保留主题色、焦点与状态反馈。

## 2026-07-21 选角视觉验收修复

桌面舞台使用共享信息层高度，将透明立绘硬裁切在档案信息层上方，避免人物腿部透入姓名、属性和操作按钮区域；移动端继续使用流式上下布局。花名册卡片以外层多边形作为唯一主题色边框，内层图面按同一斜率内缩，不再使用 `border + clip-path: inherit` 伪造斜切描边。

卡片互动拆分为稳定的选中基态和小幅 hover/focus/active 增量，轨道位置不会被旧 transform 覆盖。每张卡的等级徽章都必须与源数据一致并完整落在斜切安全区；S、A 及特殊等级均使用同一几何规则。

左侧人物舞台统一采用头部至腰/髋部的近景构图，桌面与移动端均限制源图显示下缘和纵向跨度，避免再次退化成全身小人。普通透明立绘按舞台裁切放大；爱芮、千夏缺少可信透明全身图时继续使用现有卡面，但改为无边框的 `contain` 腰部近景，不伪造透明素材，也不再使用小档案框或巨幅脸部 `cover`。

## 2026-07-21 全站动态与可读性收口

7 个核心公开页共享轻量 `site-motion.js`。脚本只注入两层状态表达：pointer / scroll 响应的克制动态信号背景，以及带有 `HOOXI // LOADING`、档案信号状态和进度轨的同源页面转场。动态不承担内容读取，不劫持历史、不锁滚动，也不使用满屏光球、持续扫描线、随机噪点或无意义 3D；`prefers-reduced-motion` 下信号背景保持静态，页面转场取消空间位移。

编辑器不接入该公共遮挡层，维护工作台始终保持直接可操作。角色详情的资料卡、标签、模块导航和长文统一为深色表面与浅色正文，移动端不产生横向溢出；代理人选角页在保留腰部近景、compact 分支、平行斜切和等级徽章几何的前提下，强化左侧人物/信息层与右侧名单、标题和筛选控件的视觉层级。

## 2026-07-21 花名册姓名与视觉密度约束

花名册姓名必须完整显示在 18% 平行斜切的底部安全区内，不使用省略号隐藏角色名；极长姓名允许定点缩小字号，但不得遮挡等级徽章或越出卡片多边形。三列和响应式双列通过列向负偏移互相咬合，桌面相邻可见斜边保持约 0–8px 细缝，纵向行缝保持约 0–6px，同时保留轻微递减的轨道错位、hover/selected 组合变换和 reduced-motion 静态位置。

## 2026-07-23 动效验收收口

共享动效层统一禁用旧 `.ambient i` drift 与 stories `.agent-roster-ticker` 的持续循环，并清除对应 `will-change`。`prefers-reduced-motion: reduce` 初始加载时，阵营页不挂载成员卡 pointer 深度交互；本轮不改变内容可用性或页面路由。

## 2026-07-25 首页“午夜放映档案”首刀

2026-07-23 的 Dual Gate 已扩展为七幕 **Seven-Act Midnight Screening Scroll**，并保留在序幕：正式查档为主行动，PLAY 为可跳过次行动。当前组合是 **A 首页 + C 章节节奏**；后续内页再采用 **B 录像带索引柜**的信息密度，不在本轮把 B 的柜格语法铺到首页。首页仍是查档入口，不承载栏目正文，也不把沉浸体验设为必经流程。

首页七幕职责固定为：序幕·今晚放映负责身份、首图与行动层级；第一幕·选片提供真实查档路径；第二幕·演员表导向代理人索引；第三幕·正片导向主线与已核验媒体；第四幕·加映导向往期活动；第五幕·片后谈导向幕后与对谈；片尾·关于档案声明非官方身份、内容边界与来源原则。正式“开始查档”是主行动，PLAY 录像店是可跳过次行动。

首页配色取自已批准方向板的放映票、CRT 信号与银幕黑：放映黄 `#FBD83F`、信号青 `#2DDCDD`、银幕黑 `#18171A`。Home / Feature Reel 的中文展示标题允许使用中文展示字体例外；正文、导航、数据字段和正式子页仍遵循全站字体 token，不把该例外扩散到内页。

首页保留稳定 ID、动态内容宿主与既有栏目链接，移动端继续使用自然纵向流和底部安全区；页面尾部磁带坞保留完整播放器控件，作为不遮挡内容的次级文档流面板。后续只沿 A 的首屏放映语法、C 的章节/场次节奏和 B 的内页索引密度推进；不做视频首屏、实时 3D、官方 UI 复刻或假数据，也不以虚构在线状态、假统计和假内容填满画面。
