## 0. 一页纸摘要

### 0.1 网站是什么

**【建议】** HOOXI = Hooxi 个人品牌下的《绝区零》**剧情视频档案** + **角色关系导航**。  
用户主要在站内**找到片、看懂顺序与关联、少剧透**，再回视频平台观看。  
**HOOXI PLAY 录像店** = 可选的沉浸式入口与发现层，**不是**打开内容的唯一门槛。

### 0.2 网站不是什么

**【不做】**

- 官方绳网 / 综合大 wiki  
- 全角色数值与配装攻略站  
- 模型下载站 / 纯 WebGL 技术展  
- Active Theory 或南孚品牌复刻  
- 必须先过 3D / AI 才能查资料的门禁站  
- 开放社区、评论、投稿论坛  

### 0.3 默认 30 秒路径（【待决】可改主次）

```text
打开根地址
→ 3 秒内看懂：这是 Hooxi 的剧情录像档案
→ 一点「浏览档案」进入目录/搜索     【建议：主路径】
→ 或一点「进入录像店」走沉浸发现   【建议：副路径，可跳过】
→ 无论哪条，最终落到同一条正式档案 URL
```

### 0.4 功能优先级一览

| 级 | 功能组 | 一句话 |
|----|--------|--------|
| P0 | 主线剧情 | 按版本补课、剧透锁、上下集 |
| P0 | 搜索 | 人/阵营/版本/标题一搜就达 |
| P0 | 稳定档案页 | 可分享 URL、封面、播放入口、来源 |
| P0 | 编辑导出 | 小团队能持续改内容 |
| P1 | 角色与阵营 | 是谁、哪伙人、相关哪些片 |
| P1 | 活动 / 幕后 | 回看与品牌主场 |
| P2 | PLAY 录像店 | 气氛与随便看看 |
| P3 | 邦布 AI | 先检索，后受控 AI |
| P3 | 养成攻略块 | 有则折叠，无则不做满 |

### 0.5 视觉一句话

**【建议】** 全站一种基因：**凌晨还在营业的录像店**（档案编号、标签纸、VHS/CRT 意象、店内暖 / 店外冷、大字留白）。  
**工具页先可读，品牌页先有空气感；同一屏不要又当百科又当 TVC。**
