## 一、核心设计理念

### 1.1 官方定义的风格关键词（✅ Wikipedia 引用官方访谈）

- **复古模拟美学（Retro Analog Aesthetic）**：刻意选用 CRT 电视、VHS 录像带、街机台、翻盖手机，而非纯高科技未来感
- **充满活力的都市（Lively and Energetic City）**：官方刻意区分于"废土暗黑"赛博朋克，强调生命力与烟火气
- **都市街头文化（Urban Street Culture）**：营销活动联动涂鸦艺术家，定位为街头时尚文化载体
- **官方设计参考作品**：*Persona 5*、*Jet Set Radio*、*Hi-Fi Rush*、*Street Fighter*（均为官方引用）
- **与同厂其他游戏有意区分**：官方明确表示 ZZZ 风格"与原神、崩坏：星穹铁道有意不同"

### 1.2 制作人官方访谈原话（✅ Siliconera，2025-06-06，制作人李振宇）

> **外观服从人格**：「*Before designing each character's appearance, we first consider their personality traits, using their background to guide the visual design direction.*」

> **服装设计两大原则**：
> 1. 必须基于**现代日常服装**，契合都市设定和整体艺术风格
> 2. 必须反映**所属阵营背景**，强化角色识别度

> **"让人过目不忘"为第一标准**：在美感与合理性之间取得平衡

### 1.3 三大风格支柱

```
Y2K Industrial Punk  ×  Urban Pop  ×  Retro-Futurism
（工业朋克 Y2K）       （都市流行）    （复古未来主义）
```

### 1.4 世界观对美术的直接影响

设定城市 **New Eridu（新艾利都）** 是末世唯一幸存的城市，被超自然现象"**Hollow（空洞）**"包围。这决定了两套并行的视觉语言：

| 视觉层 | 对应叙事 | 美术特征 |
|--------|---------|---------|
| 城市层（City） | 繁荣都市 | 霓虹灯、街道招牌、市井生活、明亮饱和 |
| 空洞层（Hollow） | 超自然侵蚀区域 | CRT像素化、扫描线、信号噪点、不稳定感 |

> Wiki原文（✅）：*"The technology in the city appears to be a blend of both retro and futuristic technology, such as advanced computer systems running on arrays of CRT televisions for its display, as well as music record players and VHS tapes being the medium of choice for entertainment."*

### 2.3 角色稀有度颜色与配色规律

| 稀有度 | 颜色 |
|--------|------|
| S 级 | 金色/琥珀色（与品牌橙黄呼应）|
| A 级 | 紫色 |
| C 级 | 蓝色 |

**双轨配色系统（角色设计核心规律 ★）：**
```
主色轨道：派系色板（控制服装大面积/底色）
副色轨道：属性/元素颜色（控制发光细节/发色/武器特效）
```
发色是属性颜色最强的视觉锚点——玩家无需看标签即可识别角色属性。

### 2.4 配色规律总结

- **高对比度**：极深黑底 + 高饱和强调色，对比比值远超可读性最低标准
- **冷暖对冲**：橙黄（暖）+ 霓虹青蓝（冷），产生霓虹灯效果
- **70:20:10 原则**：大面积黑底 + 少量橙黄点缀 + 极小量霓虹蓝
- **黑白作为结构色**：棋盘格（黑+白）、警示条（黄+黑）作为装饰而非内容色

## 三、字体体系

> ⚠️ HoYoverse 未公开字体名称，以下为社区比对推断。

| 用途 | 风格特征 | 社区推断近似字体 |
|------|---------|--------------|
| 游戏标题/Logo | 定制专属字体 | 不可直接复用 |
| **英文UI标题** | 几何粗体无衬线、全大写、字间距拉宽 | **Barlow Condensed Bold**、Bebas Neue、Industry |
| 英文正文/标签 | 现代干净无衬线、中等字重 | Barlow、Inter、Noto Sans |
| 数值/HUD | 等宽或压缩型，防数字跳动 | 等宽变体 |
| **中文UI** | 现代黑体，可能有定制裁切 | **思源黑体（Source Han Sans）** 系列 |
| 日文UI | 细体/中等字重无衬线 | Noto Sans JP、源ノ角ゴシック |

**排版规律：**
- 标题：全大写 + 超大字号 + 宽字间距，街头海报感
- 装饰性文字：常见"编号式"前缀，如 `01 / CHARACTERS`、`//STATUS`
- 数值：橙黄色高亮关键数字，等宽展示
- 层级：标题 → 章节名 → 卡片标题 → 元数据，四层清晰

## 五、官网设计分析（✅ DOM 直接解析）

### 5.1 技术架构

所有官网均为 **Nuxt.js（Vue）SPA**，内容完全客户端渲染。

- 国际版：`zenless.hoyoverse.com` — Cloudflare CDN
- 国内版：`zzz.mihoyo.com` — 阿里云OSS，含米游社深度集成
- 图片格式：WebP，90%质量（`x-oss-process=image/format,webp/quality,Q_90`）

### 5.2 加载动画DOM结构（✅ 直接解析）

```html
<div class="zzz-loading">
  <div class="zzz-loading__field"></div>   <!-- 全屏暗色背景 -->
  <div class="zzz-loading__anim"></div>    <!-- 品牌动画（橙黄色主题）-->
</div>
```

### 5.3 导航栏

- 顶部固定，初始透明，滚动后 `rgba(0,0,0,0.85)` 加深
- 高度约 60–70px
- 布局：Logo左 / 全大写导航链接中 / 语言+登录+社交图标右
- 活跃状态：橙黄色下划线或高亮

### 5.4 Hero 区域

- 满屏宣传视频（100vw×100vh，静音自动播放）
- 叠加：游戏Logo + 版本Slogan + "DOWNLOAD NOW" CTA（橙黄色）
- 角色群像从画面两侧向中央延伸

### 5.5 动效体系

| 动效类型 | 触发 | 描述 |
|---------|------|------|
| 视频背景 | 页面加载 | Hero区静音自动循环 |
| 视差滚动 | 滚动时 | 背景与前景角色不同速率 |
| 扫光效果 | hover | 高光从左到右扫过按钮/卡片 |
| 滚动入场淡入 | 滚动触发 | 从下20px上移+淡入 |
| 故障闪烁 | 装饰性偶发 | 局部文字glitch动画 |
| 粒子/光点 | 常驻背景 | 散落发光粒子浮动 |

### 8.3 Y2K 元素清单（✅ 多来源交叉确认）

Y2K/复古元素是 ZZZ 服装与同期 gacha 差异化的核心武器：

- 荧光拼色（紧身衣 + 对比色拼接）
- 铆钉/链条饰品（硬核朋克感）
- 窄腿/过膝高筒靴（2000年代流行廓形）
- 腰部包/斜跨迷你包
- 厚底松糕鞋/老爹鞋
- 格纹图案（苏格兰格、方格）
- 透明/镂空 PVC 材质
- 胶帯感或贴纸感印花
- 超短夹克配低腰裤
- 运动条纹（Adidas 式线条）

### 8.4 服装配色规律（⚠️ 基于社区观察归纳）

同一角色服装遵循"**3色以内主配色 + 1-2个属性发光点**"原则：
- 大面积底色（70%）：通常是深色或中性色
- 对比强调色（20%）：呼应所属派系
- 发光/高亮细节（10%）：呼应元素属性颜色（电=黄、冰=蓝...）

### 8.5 服装细节密度

**越高稀有度，细节越密集**，但基础廓形（剪影）保持干净：
- S 级：领口/袖口/腰部有亮丽的金属质感装饰；皮革纹理；胶印图案；隐藏图案细节
- A 级：一个主装饰点 + 清洁底色
- 设计哲学：从 5 米外能识别派系剪影，近看才发现材质和花纹细节

## 九、地图与城市场景设计

### 9.1 新艾利都（New Eridu）城市架构（✅ ZZZ Fandom Wiki）

**世界观基础**：末世后全球唯一幸存的城市，依靠从"空洞"提取以太资源的技术存活。空洞工业化和商业化是城市经济核心。

**核心叙事矛盾，直接驱动场景美术**：

| 矛盾面 | 视觉表现 |
|--------|---------|
| 繁华都市 ↔ 空洞随时吞噬街区 | 霓虹街道 VS 异色浓雾包围 |
| 先进科技 ↔ 刻意保留的复古媒介 | 量子计算机 + CRT电视并存 |
| 城市秩序 ↔ 帮派与暗流 | 精心装饰的商业区 + 破败废弃区 |

### 9.2 主要城区视觉分析（✅ Fandom Wiki + 官方设定）

**Sixth Street（第六街）— Cunning Hares 根据地**
- 霓虹招牌密度最高的商业区，色调：暖黄/橙/蓝绿对比
- Random Play 录像出租店：黑白棋盘格地板，怀旧磁带货架，复古美学浓度最高
- 街边摊档：参考日本横丁/香港旺角，纵深感强的小街道

**Lumina Square（流光广场）— 高档商业区**
- 大型商城外观，多层空中连廊，全息广告牌
- 色调偏冷：蓝灰+银白+紫色霓虹，体现高端品牌感
- 维多利亚家政公司总部所在地，建筑有维多利亚式装饰窗框

**Belobog Industrial Zone（白博格工业区）**
- 重工业厂房，生锈金属质感，体量感巨大
- 色调：深锈红+煤灰+安全黄，工业警示条纹
- 大型施工器械作为背景景观

**Hollow Interior（空洞内部）**
- 现实规律失效的异空间
- 视觉特征：现实建筑+异化变形+渐变色霾层+信息噪点
- 阵营或主题对应不同空洞风格（军事区域=铁锈迷彩；商业区=奇异广告牌扭曲）

**Wii Peninsula（威威半岛，2.0版引入）**
- 海滨悬崖城区，建筑受粤港/东南亚影响
- 色调从都市霓虹转为：海蓝 + 陶瓷白 + 暖米黄，视觉上更冷淡古典
- 第二季最明显的场景风格转变

### 9.3 环境设计的标志性密度

场景中高密度叠加的视觉图层（自下而上）：
1. 地面：棋盘格/水迹/油污/电缆沟
2. 墙面：涂鸦 + 广告海报 + 电子屏 + 管道
3. 中景：商铺招牌（多国语言混排）+ 小摊位
4. 高处：建筑外廊 + 空中广告牌 + 霓虹管道
5. 天空：城市夜景 + 空洞异色光晕

这种密度刻意参考**香港旺角、东京新宿歌舞伎町、首尔弘大**的视觉感受。

## 十、W-Engine（武器引擎）设计

### 10.1 核心设计决策（✅ Fandom Wiki）

W-Engine **不是传统意义上的刀剑枪械，而是球形装置**——这是整个武器系统与其他 gacha 游戏的最大差异。

**名称的双重含义：**
- 官方中文名「**音擎**」（Yīnqíng）= 音（声音/声波）+ 引擎
- "W" = **Wave（声波）**，而非 Weapon
- 世界观逻辑：声波可以防御空洞侵蚀（Corruption），因此武器本质是"声波发生器"

### 10.2 视觉风格

| 维度 | 描述 |
|------|------|
| 形态 | 球形精密装置，偏科技/机械工程感 |
| 材质联想 | 「声波」「音频」主题拉入复古/模拟质感（黑胶、磁带、音箱） |
| 稀有度层级 | S-Rank 专属：战斗中触发角色专属视觉特效，武器即"特效载体" |
| 命名风格 | 跨度极大：机械工业 → 音乐 → 神秘 → 美食 → 动物 → 角色主题 |
| 统一廓形 | 球形"引擎"轮廓始终统一，命名与外观材质多元化 |

### 10.3 分类对应关系

| 专精类型 | 对应角色职能 |
|---------|------------|
| Attack（进攻）| 主C输出 |
| Anomaly（异常）| 异常积累 |
| Stun（失衡）| 控制 |
| Support（支援）| 辅助 |
| Defense（防御）| 坦克 |
| Rupture（断裂）| 新专精（近期版本新增）|

邦布最初由「空洞猎人·日升者」设计，用于在空洞灾难中引导居民撤离，现已广泛应用于民用/工业/执法/军事场景。共有 **41 个可获取战斗邦布**（截至调研版本）。

### 11.2 固定设计元素（品牌锚点）

```
圆球形身体（约齐膝高）
      ↓
头顶双兔耳
      ↓
黑色屏幕面板（非真实五官，数字显示器）
      ↓
屏幕上圆形彩色眼睛
      ↓
机械结构 + 充电接口（臀部）
```

**发音模式**：「Ehn-ne」（官方设定统一叫声）

- 外壳颜色和表面处理
- 眼睛颜色和显示风格
- 服装与配件（**视觉身份的核心区分项**）
- 功能型设备和专用附件
- 尾部组件（保护接口或充当其他装置）
- 针对特定职业/组织的体型改型

### 11.4 派系邦布映射规律

## 十二、战斗视觉特效（VFX）设计

### 12.1 属性 × 颜色 × 特效三合一系统（✅ Prydwen.gg 数据 + YouTube 合集验证）

战斗视觉的组织逻辑：**一个属性绑定一种主色，一种主色决定所有相关特效颜色**。

| 属性 | 特效色 | 特征描述 |
|------|--------|---------|
| 电（Electric） | 黄金闪电 | 分叉弧状放电，快速短暂 |
| 火（Fire） | 橙红焰爆 | 膨胀爆炸，拖尾粒子 |
| 冰（Ice） | 冷蓝冰晶 | 结晶化扩散，晶棱折射 |
| 以太（Ether） | 紫色能量流 | 旋涡/晕圈，神秘感 |
| 物理（Physical） | 灰白冲击波 | 动感冲击感，无发光 |
| 风（Wind） | 绿色气流 | 螺旋上升，轻盈感 |
| 流光（Lumiflux） | 粉紫光晕 | 光谱散射，梦幻感 |

### 12.2 视觉节奏分层（✅ YouTube 技能合集视频分析）

战斗视觉按强度分四层递进：

```
普通攻击    →  Chain Attack  →  EX Special  →  Ultimate
（低密度）      （慢动作镜头）    （角色特写）     （全屏爆发）
```

- **Ultimate（终结技）**：视觉密度峰值，全屏特效 + 镜头切入角色特写 + 独有动画序列
- **Chain Attack（连携攻击）**：触发条件：将敌人削至 Daze 状态；慢动作 + 多角色轮流衔接
- **邦布连携攻击**：独立冷却，不占主连携名额，视觉上作为额外"彩蛋层"叠加
- **参考视频**：[All 56 Character Ultimates (v1.0–3.0)](https://www.youtube.com/watch?v=TeEDsEBhUY4)（Elehayym，57章节）

### 12.3 特效视觉风格关键词

- 动漫式帧爆发（非写实爆炸）
- 格斗游戏出招特效（Street Fighter 影响）
- 高饱和度局部强光（bloom + 色散）
- 画面边角的喷溅残影
- 慢动作+速度线（漫画感）
