## 网站定位

HOOXI 是一个专注于《绝区零》剧情内容的粉丝档案站，由 UP主 Hooxi 运营。网站收录了游戏主线剧情、角色PV、幕后访谈、活动攻略等视频内容，并提供了完整的角色与阵营资料库。

**核心特色：**
- 全网首个绝区零剧情视频归档站点
- ZZZ 官方视觉风格深度还原（CRT 扫描线、黄黑警示条纹、工业化 UI）
- 57 个代理人完整资料 + 18 个阵营档案
- 127+ 条精选委托（剧情/活动/幕后/对谈）

## 部署说明

### 1. GitHub Pages 线上地址

**访问地址**：https://pokkan39.github.io/hooxi-zzz/

- 每次推送到 `main` 分支后，GitHub Actions 自动构建并部署
- 约 2-3 分钟后生效
- 无需手动操作，直接访问即可

### 2. 本地预览方式

如需本地查看或二次开发：

```bash
# 克隆仓库（警告：包含 3.8GB Git 历史）
git clone https://github.com/Pokkan39/hooxi-zzz.git
cd hooxi-zzz

# 安装依赖
npm install

# 启动开发服务器
npm run dev
# 浏览器访问：http://localhost:5173/

# 构建生产版本
npm run build
# 输出目录：dist/
```

**注意**：
- **Git 仓库完整克隆约 3.8GB**（包含历史提交和 `.git` 目录）
- **生产构建输出 `dist/` 约 3.8G**（纯静态资源，不含 Git 历史）
- 如只需部署包，请使用下方自动打包版本

### 3. 轻量部署包（推荐）

为避免下载巨大的 Git 历史，项目已配置 GitHub Actions 自动发布部署包：

- **下载地址**：https://github.com/Pokkan39/hooxi-zzz/releases
- **包含内容**：
  - 构建后的静态文件（`dist/` 目录全部内容）
  - 必要的资源文件（图片、字体、样式表）
  - 无 Git 历史、无开发文件、无临时截图
- **使用方式**：
  1. 下载最新 `hooxi-zzz-deploy-vX.X.X.zip`
  2. 解压到 Web 服务器根目录
  3. 用浏览器访问 `index.html`

**与完整克隆的区别**：

| 项目 | 完整克隆 | 轻量部署包 |
|------|----------|------------|
| 大小 | 约 3.8GB | 约 3.8G（仅静态资源） |
| Git 历史 | ✅ 包含 | ❌ 不含 |
| 开发文件 | ✅ 包含源码 | ❌ 仅构建产物 |
| 适用场景 | 二次开发 | 直接部署 |
