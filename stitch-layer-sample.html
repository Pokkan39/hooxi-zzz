Section 01 / hero

四个版块共用同一张底

缝合层是单一固定背景层，跨全部版块连续。滚动时它不随内容走，三层字以不同速率做视差，产生纵深。这是「页面之间不像各做各的」的结构性解法——不是靠每页各自加装饰，而是靠一张贯穿全站的底。

Section 02 / grid

卡片网格不被干扰

缝合层明度压到 6%–8.6%，不与内容争视觉层级。卡片切角引用 --clip-card，与缝合层斜切同源，几何语言统一。

01

尺度落差

超大字被视口裁切，只露笔画，读成纹理而非词。

02

深度分层

三层不同尺度与视差速率，产生纵深而非平面贴图。

03

动效绑定任务

入场揭示与滚动视差，无循环漂移、无闪烁、无扫光。

04

单强调色

仅中层带琥珀色，其余为冷白，用量克制。

Section 03 / prose

长文段落照样可读

缝合层用纵向遮罩向下渐隐，越往下越虚，正文区域几乎不受影响。这条保证了它能铺在长滚页面上而不牺牲可读性——第 11 节无障碍门槛优先于视觉效果。

滚动时三层以 -46／-92／-150 三档速率位移，远层慢、近层快，视差方向一致。速率差是纵深的唯一来源，不靠模糊也不靠缩放。

Section 04 / tail

滚到底仍是同一张底

从首屏到页尾，背景没有换过。这与「每个版块各自配一张背景图」是两种完全不同的做法——后者版块越多越碎，前者版块越多越整。

这是样板，不是正式站页面。手法来源：镜像站用倾斜重复大字水印做单一背景层跨版块连续，顶部锚定向下渐隐。

本样板差异：字样为 HOOXI 自制（不使用官方 Logo 与品牌文案）；渐隐用 CSS 遮罩而非 PNG 内嵌，可随 token 调整；斜切角度引用 --zzz-skew，缓动引用 --ease-out，与全站同源。

v1 已废弃：33px 小字均匀平铺 370 次，每个词完整可读，读成墙纸。v2 改为尺度落差 + 深度分层 + 动效绑定任务。

未接入正式站，未改动任何现有页面。prefers-reduced-motion: reduce 下无视差、无入场动画，直接抵达最终状态。
